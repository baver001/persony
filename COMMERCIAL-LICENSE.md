# Persony Commercial Licensing

Persony uses a dual-licensing model.

The open-source code in this repository is available under the GNU Affero General Public License v3.0 only (AGPL-3.0-only), unless a file or directory explicitly states otherwise.

A separate commercial license may be obtained from the Persony copyright holder(s) for organizations that want to use, modify, distribute, embed, or offer the covered Persony code under terms that do not require compliance with the AGPL.

Typical reasons to request a commercial license include:

- offering a proprietary hosted service based on modified Persony code without publishing the corresponding source as required by the AGPL;
- embedding Persony code into a proprietary product where AGPL obligations are not acceptable;
- distributing a closed-source derivative;
- obtaining negotiated commercial terms, warranties, support, or enterprise rights.

## What a commercial license does not automatically include

Unless expressly agreed in writing, a commercial software license does not grant rights to:

- the Persony name, logos, branding, or domain names;
- Persony Cloud accounts, infrastructure, managed AI usage, hosted registry, hosted datasets, or user data;
- third-party models, APIs, datasets, fonts, images, or other assets subject to their own terms;
- any marketplace, creator, payment, or hosted-service rights not explicitly included in the agreement.

## Hosted Persony Cloud

The hosted Persony Cloud service is a separate commercial service. Availability of Persony source code under AGPL-3.0-only does not create a right to access or resell Persony Cloud services, infrastructure, data, accounts, provider credentials, or network services.

## Contributions

Before accepting substantial third-party contributions, Persony may introduce a Contributor License Agreement (CLA) or another contribution policy so that the project can continue to offer both AGPL and commercial licensing. Until such a policy is published, contribution acceptance should be reviewed case by case.

## Commercial licensing inquiries

Commercial terms are negotiated separately with the Persony copyright holder(s). A dedicated licensing contact will be published before commercial licenses are offered broadly.

This document is an explanation of the intended licensing model and is not itself a commercial license grant. A commercial license exists only when separately agreed in writing by the relevant copyright holder(s).
